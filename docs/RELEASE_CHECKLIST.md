# Release checklist

- [x] New GitHub repository exists; SSH and connected-app access verified.
- [ ] Author-approved licences installed for scripts, models and data.
- [ ] All staged assets screened for solver/training code, secrets and local paths.
- [x] Initial inference tests and immutable model hashes pass.
- [ ] Public data coverage and missing tiers are stated explicitly.
- [x] Authenticated Zenodo draft created; reserved DOI: 10.5281/zenodo.24046881.
- [ ] Bulk files uploaded with checksum readback; real access links installed.
- [ ] GitHub release tag bound to the verified commit and archived version.
- [ ] Citation metadata and manuscript data statement refer to that exact version.

A reserved DOI is a draft identifier, not a published record. Do not insert an invented DOI or claim data are deposited before upload. No core solver or training implementation belongs in any release.
